### function event\_handler 

_Internal WiFi event handler._ 
```C++
static void event_handler (
    void * arg,
    esp_event_base_t event_base,
    int32_t event_id,
    void * event_data
) 
```



Handles WiFi and IP events generated by the ESP-IDF event loop.


Events handled:
* WIFI\_EVENT\_STA\_START
* WIFI\_EVENT\_STA\_DISCONNECTED
* IP\_EVENT\_STA\_GOT\_IP






**Parameters:**


* `arg` User argument (unused) 
* `event_base` Event base 
* `event_id` Event identifier 
* `event_data` Event data payload
