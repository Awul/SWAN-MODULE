function sht40_activate_heater

Activate the SHT40 heater. 

esp_err_t sht40_activate_heater (
    sht40_t * dev
)

Enable or disable the heater.

Heater is mainly for anti-condensation. Should not be used during measurement. Heater commands are defined in the sht40_cmd_t enum. This function uses the high power long duration command.

Parameters:

  • dev Pointer to sht40_t struct

Returns:

ESP_OK on success
